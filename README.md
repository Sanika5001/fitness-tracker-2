# FitTrack

A lightweight C++17 and vanilla JavaScript fitness tracking web app.

## Build and Run
1. Run `./setup.sh` to download single-header dependencies.
2. Compile: `g++ -std=c++17 -O2 -pthread backend/main.cpp -o server`
3. Start: `./server` and browse to `http://localhost:10000` (or configured PORT).
